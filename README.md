I am a **Computer Science and Business Systems student at KIT's College of Engineering, Kolhapur**, focused on building practical systems across **data analytics, AI/ML, software engineering, and full-stack development**.

My work combines analytical thinking with engineering fundamentals — from transforming raw datasets and designing KPI-driven dashboards to building recommendation systems, REST APIs, database-backed applications, and machine-learning workflows.

<summary><strong>CETCampus — MHT-CET Engineering Recommendation Platform</strong></summary>

### CETCampus

A full-stack, data-driven **MHT-CET engineering college recommendation platform** designed to help students discover, compare, filter, and shortlist Maharashtra engineering colleges using historical CAP cutoff data.

The platform uses a transparent recommendation methodology rather than a black-box admission probability model.

| Attribute | Details |
|---|---|
| **Stack** | Next.js 15, TypeScript, Tailwind CSS, FastAPI, Python, Pandas, SQLAlchemy, PostgreSQL, Supabase |
| **Scale** | 28,377 historical CAP cutoff records · 326 institutions · 94 disciplines · 77 seat categories |
| **Performance** | 65 backend unit/integration tests; frontend build reported zero TypeScript/linting errors |
| **Security** | Environment-based database configuration with `.env.example`; structured API/database separation |
| **Impact** | Personalized college discovery, transparent Safe / Moderate / Reach classification, comparison, shortlisting, prediction history |
| **Repository** | [GitHub Repository](https://github.com/Adiitya09/CETCampus) |

#### Engineering Scope

- Developed a recommendation engine around historical cutoff margins and student-specific preferences.
- Implemented transparent **Safe, Moderate, and Reach** classification.
- Integrated percentile, branch, seat type, location, and historical cutoff data.
- Built a college directory covering **326 institutions**.
- Implemented college profiles with branch-level cutoff analysis.
- Added multi-college comparison for up to four colleges.
- Developed candidate shortlisting and prediction-history workflows.
- Designed an ingestion pipeline for future `.xlsx` dataset updates.
- Connected the recommendation layer to FastAPI and a Next.js frontend.
- Structured the system around frontend, API, database, data, pipeline, documentation, and test layers.

</details>
